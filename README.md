# FaceWag

Recognizing emotional states in dogs from their facial expressions is important for animal welfare, but it is unclear which facial cues humans and machines rely on.

A recent deep learning model distinguished positive anticipation from frustration in dogs with about 89% accuracy, but it is unknown whether humans look at the same facial regions or make the same mistakes.

This project will build a web-based eye-tracking experiment in which dog professionals and laypeople classify dog images on which the model was either right or wrong.

We will compare the accuracy and gaze patterns of professionals, laypeople and the model to understand which facial regions lead to correct and incorrect recognition.
